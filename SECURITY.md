# Security Policy

## Supported versions

The latest source on the `main` branch and the latest published WinUtilX release are the versions intended to receive fixes.

## Reporting a vulnerability

Please do not publish exploit details, private data, or a working proof of concept in a public issue.

If GitHub's **Report a vulnerability** option is available in this repository's Security tab, use it. Otherwise, contact the maintainer through the GitHub profile at https://github.com/MohamedBabaamer and include the affected version, impact, and minimal reproduction steps. Please allow time for investigation before sharing details publicly.

WinUtilX can change Windows settings and registry values. Test on a non-critical machine or create a restore point before applying system-level changes.
